/Sobhaty

A modern, ad-free digital tasbeeh for daily dhikr, published on Google Play.

Sobhaty is an electronic tasbeeh built to make daily dhikr simple, with a calm interface and no advertising. I designed, developed and published it on my own, from the first Compose screen to the Play Store listing.

The app follows the MVVM pattern: a ViewModel holds the counter state, a repository talks to a Retrofit service, and Jetpack DataStore keeps the counter and settings between sessions. A Glance home-screen widget lets people count without opening the app.

#highlights

  • Several adhkar: tasbeeh, istighfar and salawat on the Prophet ﷺ
  • Adjustable daily goal
  • Privacy mode that hides the counter and cards in public places
  • Light and dark themes, plus a full-screen focus mode
  • Haptic feedback on every count
  • Interactive home-screen widget built with the Glance API
